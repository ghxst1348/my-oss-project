# AI-Enhanced Task Automator

An open-source Python tool designed to automate repetitive daily workflows using OpenAI's powerful models. This project aims to bridge the gap between traditional automation scripts and intelligent AI processing.

## 🌟 Features
- **Smart Email Summarization**: Automatically processes long email threads and generates bullet-point summaries.
- **Code Docstring Generator**: Parses code repositories and automatically writes standard Google/NumPy style docstrings for functions.
- **Data Extractor**: Converts unstructured text data (like invoices or logs) into clean JSON format.

## 🛠️ Tech Stack
- Python 3.9+
- OpenAI API
- Python-dotenv
